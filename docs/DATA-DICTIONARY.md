# 客流观测与区间

区域人数与两两交集必须是非负整数，单位人或千人。东门、中庭、西门映射为A、B、C。时间先转UTC后形成小时桶；非整点观测向下归入所在UTC小时桶。同一观测按version选择最高版，矛盾同版隔离。

最多三个区域。两区域无交集观测时联合人数为[max(A,B),A+B]；已知交集I时为A+B-I。三区域需要全部两两交集。三方交集T下界为max(0,AB+AC-A,AB+BC-B,AC+BC-C)，上界为min(AB,AC,BC)。联合人数为A+B+C-AB-AC-BC+T。区间无可行整数时整桶隔离。输出上下界，不估算未经观测的精确人数。日汇总是分桶客次的上下界相加，不宣称是全天独立人数。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

三方交集仅在A、B、C三个区域齐全时适用，类型triple的left必须为ABC，right必须为空。

支持区域固定为A、B、C；其他区域标识拒绝，防止三方ABC记录关联到另一组区域。

## 晚班交接（M8）

容量线 capacity 为正整数参数，缺省 240。逐桶对 M5 的人数区间 [lower, upper] 裁决，页面清单、交接单与处置状态共用同一函数：

- lower > capacity：已超限（CONFIRMED）；
- lower ≤ capacity < upper：跨线待证（CROSSING），区间跨过容量线但未证实；
- upper ≤ capacity：未超限（CLEAR），不进入交接清单。

相邻 UTC 小时且裁决相同的风险时段合并为一条处置记录，记录号 R{seq} 在交接单内固化，处置状态为 待处置/处置中/已处置。交接单按业务日追加 sheet_no 版本链：待签收、已签收、已替换。晚到数据补发只追加新版，redecided 列出新增风险、结论变化、解除风险的时段；已签收单内容不可改写，处置记录随版本链携带。(业务日, run_id) 唯一，同批重跑幂等不新增风险段；补发事务失败回滚并保留旧版。
